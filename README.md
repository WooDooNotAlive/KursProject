# BankWidget — анализ банковских транзакций

Курсовая работа: приложение читает выписку из Excel, считает аналитику
и отдаёт готовые JSON-ответы для веб-страниц, а также формирует отчёты
в файлы.

## Что реализовано

**Веб-страницы (`src/views.py`)**

| Функция | Что возвращает |
|---|---|
| `main_page(date_time)` | приветствие по времени суток, расходы и кешбэк по каждой карте, топ-5 транзакций, курсы валют, цены акций |
| `events_page(date_time, period="M")` | расходы (топ-7 категорий + «Остальное», отдельно переводы и наличные), поступления, курсы валют, цены акций; периоды `W` / `M` / `Y` / `ALL` |

**Сервисы (`src/services.py`)**

| Функция | Что делает |
|---|---|
| `cashback_categories(data, year, month)` | сколько кешбэка (1 %) можно получить по каждой категории за месяц; переводы и наличные исключены |
| `investment_bank(month, transactions, limit)` | сумма, которую удалось бы отложить в «Инвесткопилку» при округлении трат до шага 10/50/100 ₽ |
| `simple_search(transactions, query)` | поиск по подстроке в описании или категории без учёта регистра |
| `phone_search(transactions)` | транзакции с мобильным номером в описании (`+7 995 555-55-55`, `8 (900) 000-00-00`, `89000000000`) |
| `transfers_to_people(transactions)` | переводы физлицам: категория «Переводы» + «Имя Ф.» в описании |

**Отчёты (`src/reports.py`)**

| Функция | Что делает |
|---|---|
| `spending_by_category(transactions, category, date=None)` | траты по категории за последние 3 месяца |
| `spending_by_weekday(transactions, date=None)` | средние траты по дням недели за последние 3 месяца |
| `spending_by_workday(transactions, date=None)` | средние траты в рабочий и выходной день |

Все отчёты обёрнуты в декоратор `@report`: без параметра имя файла
генерируется автоматически (`reports/<функция>_<дата>_<время>.csv`),
с параметром — `@report("my_report.csv")` — используется указанное имя.

## Запуск

```bash
python -m src.main
python -m src.main --date "2021-12-31 16:44:00" --period M
```

Скрипт печатает JSON главной страницы и страницы «События», результат
работы всех сервисов и сохраняет три отчёта в `reports/`.

Использование из кода:

```python
from src import utils, views

frame = utils.read_transactions("data/operations.xlsx")
json_answer = views.main_page("2021-12-31 16:44:00", frame)
```

## Данные

`data/operations.xlsx` — выписка из 6705 операций за 2018–2021 годы
(лист «Отчет по операциям»). Поддерживаются оба формата: `.xlsx`
(через `openpyxl`) и исходный `.xls` (через `xlrd`).

Имя файла используется только в `utils.read_transactions()`; все
остальные функции принимают готовый `DataFrame` или список словарей,
поэтому бизнес-логику легко тестировать на синтетических данных.

## Валюты и акции

Список валют и акций задаётся в `user_settings.json`:

```json
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}
```

Источники (без API-ключа):

* курсы — API ЦБ РФ (`cbr-xml-daily.ru`), резерв — `open.er-api.com`;
* акции — Yahoo Finance (узлы `query1` и `query2`).

Ответы кешируются на 6 часов в `data/cache/api_cache.json`, запросы
повторяются дважды, ошибки сети логируются. Если данные получить
не удалось, приложение не падает: отдаёт закешированные значения,
а при их отсутствии — `0.0` и предупреждение в лог.

## Принятые допущения

* **Топ-5 транзакций** — сортировка по «Сумме платежа» по убыванию
  среди успешных операций за период (как в критериях: «отсортированы
  по убыванию поля amount»).
* **Кешбэк по карте** — 1 ₽ на каждые 100 ₽ расходов: `total_spent / 100`,
  округление до копеек.
* **Расходы** — операции с отрицательной «Суммой платежа», **поступления** —
  с положительной; в расчётах участвуют только операции со статусом `OK`.
* **События**: «Основные» — топ-7 категорий, остальное суммируется
  в «Остальное»; «Переводы» и «Наличные» вынесены в отдельный блок
  и в топ не попадают. Суммы округляются до целых рублей.
* **Кешбэк по категориям** — 1 % от суммы расходов категории
  (параметр `rate` можно изменить), результат — целые рубли.
* **Средние траты** в отчётах считаются по дневным суммам: сначала
  складываются все траты за день, затем усредняются по дням недели
  (или по типу дня).
* **Границы периодов** включают дату целиком (`23:59:59`).
* «Последние три месяца» — интервал `(дата − 3 месяца; дата]`.

## Соответствие критериям

| Критерий | Где смотреть |
|---|---|
| Приветствие по интервалу 06–11 / 12–17 / 18–22 / 23–05 | `views.get_greeting` |
| Информация по картам: последние 4 цифры, расходы, кешбэк | `views.build_cards` |
| Ровно 5 транзакций по убыванию суммы, дата `dd.mm.yyyy` | `views.build_top_transactions` |
| Все валюты из настроек, курс > 0 | `views.main_page` → `currency_rates` |
| Все акции из настроек, цена > 0 | `views.main_page` → `stock_prices` |
| Расходы/поступления/курсы/акции, топ-7 + «Остальное», переводы и наличные, округление | `views.events_page` |
| Ошибки API обработаны | `external_api` (ретраи, кеш, fallback-источники) |
| Не менее 3 категорий кешбэка | `services.cashback_categories` |
| Поиск по подстроке без учёта регистра | `services.simple_search` |
| Поиск телефонов в разных форматах | `services.phone_search` |
| Переводы физлицам | `services.transfers_to_people` |
| Отчёты + декоратор | `reports.py` |
